# Bjorn Kurk Cruz | Portfolio

Static site. No build step. Files: `index.html`, `style.css`, `script.js`, `images/`.

## Run
Open `index.html`, or `npx serve .`

## Deploy
- GitHub: push this folder to a repo.
- Vercel: Import the repo, framework preset "Other", no build command, output directory `.`

## Replace before submitting
- `images/profile.jpg` (4:5 portrait)
- Email `bjorn@example.com` in `index.html`
- GitHub / LinkedIn / project links (`your-username`)
- Placeholder skills and project text (search for `TODO`)

## Design
Palette: `--bg`, `--ink`, `--accent`, `--muted` in `:root`. Fonts: Bricolage Grotesque (display), IBM Plex Mono (body).
